## S01 — 사전조건 저장 (V1)

- Figma: https://www.figma.com/design/Hglcm6D0cuZGSkZjInwxO7/공모전팀?node-id=665-7694&m=dev (node `665:7694`, "Cell · 01 사전조건 저장 · V1")
- Nav 타이틀: `신용대출 조회 결과`
- 목적(PRD 8장): 신청 시점의 V1 봉인과 유효기간 안내

**화면 구성**
- Heading: "현재 신청 가능한 조건이에요" + info 아이콘(우대조건/조회결과 설명 툴팁으로 추정)
- 조건 카드
  - 대출 한도: `5,000만원`
  - 예상 금리: `연 5.20%` (강조색)
  - 기간 · 상환: `36개월 · 원리금균등`
- 유효기간 배지: "오늘 18:00까지 유효한 조회 결과입니다." — V1 만료 시각 안내 (PRD E01 사전조건 만료와 연결)
- "반영된 우대조건" 리스트 (아이콘 + 항목명 + 금리 감면폭)
  - 급여이체: `-0.30%p`
  - iM뱅크 주거래: `-0.10%p`
- Primary CTA: "이 조건으로 신청" → FR01(V1 Snapshot 생성) 트리거

**FR01 V1 Snapshot 필드 매핑**
| 화면 표시 | PRD Field Code | 비고 |
| --- | --- | --- |
| 대출 한도 | `LOAN_AMOUNT` | |
| 예상 금리 | `FINAL_RATE` | 기준금리+가산금리-우대금리 반영된 최종값으로 추정 |
| 기간 | `TERM_MONTHS` | |

| 우대조건 리스트(항목명, %p) | `PREFERENTIAL_CONDITIONS` | 항목별 감면폭까지 구조화해서 저장해야 S04에서 "우대조건 충족 확인" 변경사유로 재사용 가능 |

## S02 — 최종조건 자동 비교(진행 중)

- Figma: https://www.figma.com/design/Hglcm6D0cuZGSkZjInwxO7/공모전팀?node-id=665-8267&m=dev (node `665:8267`, "Cell · 02 최종조건 자동 비교")
- Nav 타이틀: `iM 조건체크`
- 목적(PRD 8장): 추출·정규화·비교·계산 진행상태 표시, 완료 시 S03으로 자동 전환

**화면 구성**
- 중앙 비주얼: V1 문서 ↔ V2 문서 아이콘 + 진행률 원형 게이지 `75%` + `6 / 8 항목`
- Heading: "최종 조건을 비교하고 있어요"
- 서브텍스트: "사전조건(V1)과 최종 약정조건(V2)의 같은 항목을 연결해 비용 영향을 계산합니다."
- 진행 단계 체크리스트 (완료 항목은 체크 아이콘, 진행 중인 항목은 `···`)
  1. 대출금액·금리 연결 — 완료
  2. 우대조건 충족 확인 — 완료
  3. 상환방식·기간 확인 — 완료
  4. 월 납입액·총이자 계산 — 진행 중
- 하단 CTA: "비교 결과 확인중" (비활성 상태) — Job 완료 전까지 disabled

**API 설계 시사점**
- 이 화면은 FR04~FR09(추출 → 정규화 → 비교 → 계산)를 하나의 비동기 Job으로 노출해야 한다. 폴링형이든 SSE든, 최소한 아래를 반환하는 진행상태 API가 필요:
  - `progressPercent` (예: 75)
  - `completedSteps` / `totalSteps` (예: 6 / 8)
  - 단계별 상태 리스트 — 화면의 4개 체크리스트 항목은 사용자향 요약이고, 내부 8단계(FR04~FR09 세부 처리 단위)를 4개로 묶어 보여주는 것으로 추정 → 실제 백엔드 단계 수와 화면 표시 단계 수가 다를 수 있음을 감안해 매핑 테이블을 별도로 둘 것
- Job이 실패(UNKNOWN/출처충돌 등, PRD 14.1 Overall Status)하면 이 화면에서 바로 E02(분석 불확실)로 분기해야 하므로, 진행상태 API는 `FAILED` 류 상태와 실패 사유 코드도 함께 내려줘야 한다.
- "자동 전환"이 PRD 요구사항이므로 클라이언트가 완료 여부를 즉시 알 수 있는 방식(짧은 폴링 주기 또는 SSE/WebSocket)이 필요 — 기술 스택 선택은 Non-goal(PRD 5.2)이지만 완료 신호를 어떻게 줄지는 API 계약에 포함해야 함.
